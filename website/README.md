# iNex Official Website

An independent, bilingual marketing website for the iNex product.

## Project boundaries
- Website source is isolated under `website/` on branch `website/modern-bilingual-v1`.
- The existing PWA, admin panel, Firebase configuration, Firestore rules, Cloudinary integration and backend are not modified.
- The website is static HTML, CSS and JavaScript. It does not connect to application databases or APIs.
- The existing iNex logo is reused from the source repository.
- Feature descriptions are based on capabilities documented in the repository; no new application functionality is implied.

## Local preview
Serve this directory with any static web server and open `index.html`.

## Cloudflare Pages setup (not deployed)
After explicit owner approval:
- Framework preset: None
- Root directory: `website`
- Build command: leave blank
- Build output directory: `.`
- Environment variables: none required

Do not create a production deployment or connect a production domain until the owner approves the final content, confirms the live application URL and authorizes deployment.

## Content and legal positioning
iNex is presented as an insurance-awareness and brokerage lead-generation platform. The website explicitly states that iNex is not an insurance company and does not itself issue insurance policies.
